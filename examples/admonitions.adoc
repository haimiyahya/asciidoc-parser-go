= Admonitions Showcase

This document demonstrates all admonition blocks available in AsciiDoc.

== Basic Inline Admonitions

=== Note

NOTE: This is a note admonition. Notes are used for additional information that is helpful but not critical.

=== Tip

TIP: This is a tip admonition. Tips provide helpful suggestions or best practices.

=== Warning

WARNING: This is a warning admonition. Warnings alert readers to potential issues or problems.

=== Caution

CAUTION: This is a caution admonition. Cautions warn about possible damage or data loss.

=== Important

IMPORTANT: This is an important admonition. Important blocks highlight critical information that readers should pay attention to.

== Block-Style Admonitions

Block-style admonitions use `[TYPE]` syntax above the content. This format supports multiple paragraphs and custom titles.

=== Simple Block Admonition

[NOTE]
This is a block-style note.
It can span multiple lines.

=== Block Admonition with Custom Title

[TIP]
.Quick Tip
This is a tip with a custom title.
The title is specified using the `.Title` syntax before the content.

=== Multi-Paragraph Block Admonition

[WARNING]
.Important Warning
This is the first paragraph of the warning.

This is the second paragraph with more information.
Blank lines separate paragraphs within the admonition.

=== Block Admonition with List

[CAUTION]
.Safety Precautions
* Wear protective equipment
* Follow all safety guidelines
* Report any hazards immediately

== Best Practices

=== When to Use Each Type

NOTE: Use notes for additional, non-critical information.

TIP: Use tips for helpful shortcuts or best practices.

WARNING: Use warnings for things that might cause unexpected behavior.

CAUTION: Use cautions when data loss or damage is possible.

IMPORTANT: Use important for must-know information.

=== Writing Effective Admonitions

* **Be concise** - Get to the point quickly
* **Be specific** - Clearly state what the reader should know
* **Use sparingly** - Too many admonitions reduce their impact
* **Match type to content** - Use the right admonition for the situation

== Inline vs Block Style

Inline style (`NOTE: text`) is best for:
* Single-line admonitions
* Admonitions within paragraphs
* Quick notes without titles

Block style (`[NOTE]` above content) is best for:
* Multi-paragraph admonitions
* Admonitions with custom titles
* Longer, detailed notes
* Admonitions containing lists or other structured content

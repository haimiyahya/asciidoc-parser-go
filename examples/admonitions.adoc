= Admonitions Showcase

This document demonstrates all admonition blocks available in AsciiDoc.

== Basic Admonitions

=== Note

NOTE: This is a note admonition. Notes are used for additional
information that is helpful but not critical.

=== Tip

TIP: This is a tip admonition. Tips provide helpful suggestions
or best practices.

=== Warning

WARNING: This is a warning admonition. Warnings alert readers to
potential issues or problems.

=== Caution

CAUTION: This is a caution admonition. Cautions warn about possible
damage or data loss.

=== Important

IMPORTANT: This is an important admonition. Important blocks highlight
critical information that readers should pay attention to.

== Best Practices

=== When to Use Each Type

NOTE: Use notes for additional, non-critical information.

TIP: Use tips for helpful shortcuts or best practices.

WARNING: Use warnings for things that might cause unexpected behavior.

CAUTION: Use cautions when data loss or damage is possible.

IMPORTANT: Use important for must-know information.

=== Writing Effective Admonitions

* **Be concise** - Get to the point quickly
* **Be specific** - Clearly state what the reader should know
* **Use sparingly** - Too many admonitions reduce their impact
* **Match type to content** - Use the right admonition for the situation

== Current Limitations

* Block-style admonitions (`[NOTE]` above content) are not yet supported
  * Use inline syntax instead: `NOTE: text here`
* Admonitions with custom titles (`.Title` in block style) are not yet supported
* Multi-paragraph admonitions are partially supported (second paragraph appears separately)
* Lists within admonitions render as separate blocks after the admonition

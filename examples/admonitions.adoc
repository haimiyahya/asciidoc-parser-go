== Basic Admonitions

=== Note

NOTE: This is a note admonition. Notes are used for additional information that is helpful but not critical.

=== Tip

TIP: This is a tip admonition. Tips provide helpful suggestions or best practices.

=== Warning

WARNING: This is a warning admonition. Warnings alert readers to potential issues or problems.

=== Caution

CAUTION: This is a caution admonition. Cautions warn about possible damage or data loss.

=== Important

IMPORTANT: This is an important admonition. Important blocks highlight critical information that readers should pay attention to.

== Multi-Line Admonitions

Admonitions can span multiple lines. The text continues until a blank line or different block type is encountered.

NOTE: This is the first line of the note.
This is the second line that continues the note.
This is the third line with more information.

TIP: First line of the tip.
Second line with additional details.
Third line summarizing the point.

WARNING: This warning spans multiple lines.
Each line is accumulated into the warning text.
The warning ends at the blank line below.

== Best Practices

=== When to Use Each Type

NOTE: Use notes for additional, non-critical information.

TIP: Use tips for helpful shortcuts or best practices.

WARNING: Use warnings for things that might cause unexpected behavior.

CAUTION: Use cautions when data loss or damage is possible.

IMPORTANT: Use important for must-know information.

=== Writing Effective Admonitions

* **Be concise** - Get to the point quickly
* **Be specific** - Clearly state what the reader should know
* **Use sparingly** - Too many admonitions reduce their impact
* **Match type to content** - Use the right admonition for the situation

== Current Limitations

The following features are not yet fully supported:

* Block-style admonitions (`[NOTE]` above content)
  * Use inline syntax instead: `NOTE: text here`
* Admonitions with custom titles (`.Title` in block style)
* Lists within admonitions (lists render as separate blocks after the admonition)
* Code blocks within admonitions (code blocks render separately)
* Multi-paragraph admonitions with blank lines (each paragraph renders separately)

If you need these features, consider using regular paragraphs with inline formatting or separating the content into adjacent blocks.

Basic Admonitions

Note

Note
 This is a note admonition. Notes are used for additional

information that is helpful but not critical.

Tip

Tip
 This is a tip admonition. Tips provide helpful suggestions

or best practices.

Warning

Warning
 This is a warning admonition. Warnings alert readers to

potential issues or problems.

Caution

Caution
 This is a caution admonition. Cautions warn about possible

damage or data loss.

Important

Important
 This is an important admonition. Important blocks highlight

critical information that readers should pay attention to.

Admonitions with Titles

Note with Title

This note can also have multiple paragraphs.

Caution with Title

.Be Careful! This caution block warns about potential issues. Proceed with caution.

Important with Title

.Must Read This is important information. Don't skip this section.

Best Practices

When to Use Each Type

Note
 Use notes for additional, non-critical information.
Tip
 Use tips for helpful shortcuts or best practices.
Warning
 Use warnings for things that might cause unexpected behavior.
Caution
 Use cautions when data loss or damage is possible.
Important
 Use important for must-know information.

Writing Effective Admonitions

  • Be concise - Get to the point quickly

  • Be specific - Clearly state what the reader should know

  • Use sparingly - Too many admonitions reduce their impact

  • Match type to content - Use the right admonition for the situation

Multi-Line Admonitions

Admonitions can span multiple lines. The text continues until a blank line or different block type is encountered.

Note
 This is the first line of the note. This is the second line that continues the note. This is the third line with more information.
Tip
 First line of the tip. Second line with additional details. Third line summarizing the point.
Warning
 This warning spans multiple lines. Each line is accumulated into the warning text. The warning ends at the blank line below.

Best Practices

When to Use Each Type

Note
 Use notes for additional, non-critical information.
Tip
 Use tips for helpful shortcuts or best practices.
Warning
 Use warnings for things that might cause unexpected behavior.
Caution
 Use cautions when data loss or damage is possible.
Important
 Use important for must-know information.

Writing Effective Admonitions

  • Be concise - Get to the point quickly

  • Be specific - Clearly state what the reader should know

  • Use sparingly - Too many admonitions reduce their impact

  • Match type to content - Use the right admonition for the situation

Current Limitations

The following features are not yet fully supported:

  • Block-style admonitions ([NOTE] above content)

    • Use inline syntax instead: NOTE: text here

  • Admonitions with custom titles (.Title in block style)

  • Lists within admonitions (lists render as separate blocks after the admonition)

  • Code blocks within admonitions (code blocks render separately)

  • Multi-paragraph admonitions with blank lines (each paragraph renders separately)

If you need these features, consider using regular paragraphs with inline formatting or separating the content into adjacent blocks.

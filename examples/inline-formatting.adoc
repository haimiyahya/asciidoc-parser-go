= Inline Formatting Showcase

This document demonstrates all inline formatting features available in AsciiDoc.

== Basic Text Formatting

=== Bold and Italic

// Single asterisk/underscore for italic
*Italic text* and _italic text_

// Double for bold
**Bold text** and __bold text__

// Triple for bold italic
***Bold italic*** and ___bold italic___

// Monospace
`Monospace text` and +monospace text+

== Subscript and Superscript

// Subscript
H~2~O is water. x^2^ + y^2^ = z^2^

// Superscript
E = mc^2^
The 2^nd^ element is Helium.

== Summary of Inline Formatting

|===
| Style | Syntax | Result
| Bold | `**text**` | **bold**
| Italic | `__text__` or `*text*` | _italic_
| Bold Italic | `***text***` | ***bold italic***
| Monospace | `` `text` `` or `+text+` | `monospace`
| Subscript | `text~sub~` | H~2~O
| Superscript | `text^super^` | x^2^
| Link | `link:url[text]` | link:url[text]
| URL | `https://example` | https://example.com
| Keyboard | `kbd:[key]` | kbd:[Ctrl]
| Button | `btn:[text]` | btn:[Save]
| Menu | `menu:Path[item]` | menu:File[Save]
|===

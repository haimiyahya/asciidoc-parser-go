= Lists Showcase

This document demonstrates all list types available in AsciiDoc.

== Unordered Lists

=== Basic Unordered List

* First item
* Second item
* Third item

=== Nested Unordered Lists

* Level 1 item
** Level 2 item
*** Level 3 item
**** Level 4 item
**** Level 4 item again
*** Back to level 3
** Back to level 2
* Back to level 1

=== Mixed Content Unordered List

* Item with **bold text**
* Item with _italic text_
* Item with `inline code`
* Item with https://example.com[a link]

== Ordered Lists

=== Arabic Numerals (Default)

. First step
. Second step
. Third step

=== Explicit Numbering Styles

You can explicitly specify the numbering style using markers before each item.
All items in the same list use the same style marker.

==== Lower-Alpha (a, b, c)

[a] Run the tests

==== Upper-Alpha (A, B, C)

[A] Release phase

==== Lower-Roman (i, ii, iii)

[i] Project kickoff
[i] Requirements gathering
[i] Design specification
[i] Implementation

==== Upper-Roman (I, II, III)

[I] Foundation
[I] Structure
[I] Finishing touches

==== Explicit Arabic (1, 2, 3)

== Labeled Lists (Description Lists)

=== Basic Labeled List

term 1:: Description of term 1
term 2:: Description of term 2
term 3:: Description of term 3

=== Labeled List with Extended Descriptions

First Term:: This is a longer description that spans multiple lines.

Second Term:: This also has a detailed description with multiple sentences.

Third Term:: Short description

=== Multi-line Definitions

Labeled list items can have multi-line definitions. Simply add the continuation
lines on the following lines (no need for special syntax).

Installation instructions::
Download the package from the official website.
Extract the archive to your preferred location.
Run the installer script.
Follow the on-screen prompts.

Configuration steps::
Edit the configuration file in /etc/myapp/config.yaml.
Set your preferred options and save the file.
Restart the application for changes to take effect.

== Q&A Lists (Question and Answer)

[qanda]
What is AsciiDoc?:: AsciiDoc is a text document format for writing notes, documentation, articles, books, web pages, slide decks and man pages.
How do I install it?:: Use the package manager for your system or download from GitHub.
Why use it?:: Plain text, version control friendly, easy to read, multiple output formats.

== Summary

|===
| List Type | Syntax Marker | Example
| Unordered | `*` | ``* Item``
| Ordered (dot) | `.` | ``. Item``
| Ordered (explicit) | `[a]`, `[A]`, `[i]`, `[I]`, `[1]` | ``[a] Item``
| Labeled | `::` | ``term:: description``
| Inline | N/A | ``one, two, three``
| Checklist | `-` | ``- [x] Done``
|===

== Current Limitations

* Multi-line list items without proper continuation
* Complex nested inline formatting in list items
* Multiple nested lists per item (mixed list types)
* Inline lists (text: item1, item2, and item3)
* Q&A lists with qanda attribute
* Bibliography lists

= Lists Showcase

This document demonstrates all list types available in AsciiDoc.

== Unordered Lists

=== Basic Unordered List

* First item
* Second item
* Third item

=== Nested Unordered Lists

* Level 1 item
** Level 2 item
*** Level 3 item
**** Level 4 item
**** Level 4 item again
*** Back to level 3
** Back to level 2
* Back to level 1

=== Mixed Content Unordered List

* Item with **bold text**
* Item with _italic text_
* Item with `inline code`
* Item with https://example.com[a link]

== Ordered Lists

=== Arabic Numerals (Default)

. First step
. Second step
. Third step

// NOTE: Explicit list numbering styles [a], [A], [i], [I] are not yet supported.

=== Nested Ordered Lists

. Level 1 arabic
.. Level 2 arabic
... Level 3 arabic
.. Back to level 2
. Level 1 again

=== Restart Numbering

. First item
. Second item
. Third item

[list restart]
. First item (restarted)
. Second item

== Labeled Lists (Description Lists)

=== Basic Labeled List

term 1:: Description of term 1
term 2:: Description of term 2
term 3:: Description of term 3

=== Labeled List with Extended Descriptions

First Term:: This is a longer description that spans multiple lines.

Second Term:: This also has a detailed description with multiple sentences.

Third Term:: Short description

// Note: For multi-line definitions, keep the text on the same line as the term.
// Multi-paragraph definitions are not yet supported in this implementation.

Web Browsers:: Chrome, Firefox, Safari

== Q&A Lists (Question and Answer)

[qanda]
What is AsciiDoc?:: AsciiDoc is a text document format for writing notes, documentation, articles, books, web pages, slide decks and man pages.
How do I install it?:: Use the package manager for your system or download from GitHub.
Why use it?:: Plain text, version control friendly, easy to read, multiple output formats.

== Checklists (Task Lists)

=== Simple Checklist

- [ ] Task not yet done
- [x] Completed task
- [ ] Another pending task

=== Checklist with Grouping

Shopping List:
- [x] Milk
- [x] Eggs
- [ ] Bread
- [ ] Coffee

Work Tasks:
- [ ] Review PR #123
- [x] Fix bug in table parser
- [ ] Update documentation

== Complex Examples

=== Procedure with Steps

Procedure for creating a new document:

. Create a new file with `.adoc` extension
. Add a document title (line starting with `=`)
. Write your content using AsciiDoc syntax
. Convert to your desired format

=== Definition List with Code Samples

Data Types::


Integer:: Whole numbers
```

```

Boolean:: True or false
```

```

* Plain text

* Multiple output formats

== Cons ==

== Current Limitations

* Multi-line list items without proper continuation
* Complex nested inline formatting in list items
* Custom list numbering styles
